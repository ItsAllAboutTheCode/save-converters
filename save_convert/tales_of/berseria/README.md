# Tales of Berseria Convert Notes

There is no Save Converter script in the repo for the original Tales of Berseria -> Tales of Berseria Remastered game as the save data does not need to be modified.  
However the is the [Save_NOTES.md](./save_NOTES.md) document details how to load the an original Tales of Berseria PC save to Remastered PC save.  

Furthermore conversion from the PS4 to PC versions also do not require any data modification either.  
The decrypted PS4 save would need to be extracted using Apollo on PS4 or Garlic Save Manager on PS5.
