# Save Notes (original PC -> remaster PC)

The Remaster version of Tales of Berseria can load an original PC save, however the original PC save will not be recognized by the load menu.  

So in order to load an original, the Load menu must first be opened up with only the remaster PC save within the save folder.
Once the load menu is opened up, one of the remastered saves can be replaced with the original PC save in the save folder.
Afterwards attempting to load the save should work.
